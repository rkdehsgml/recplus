# 레크플러스 UI 시스템

이 문서는 게임 카테고리 팔레트와 공통 사이드바를 다른 화면에서도 일관되게 사용하기 위한 기준이다.

## 카테고리 팔레트

원본 토큰은 `src/app/design-tokens.css`, 게임 유형 매핑은 `src/lib/game-palette.ts`가 단일 기준이다.

| 팔레트 | Surface | Text/Icon | Accent | 현재 게임 유형 |
| --- | --- | --- | --- | --- |
| 퍼포먼스 | `#F3E8FF` | `#7E22CE` | `#A855F7` | `PERFORM` |
| 토크 | `#F1F5F9` | `#475569` | `#64748B` | `TALK` |
| 스피드/긴장 | `#FEF9C3` | `#A16207` | `#EAB308` | `BOMB` |
| 퀴즈/상식 | `#E0F2FE` | `#0369A1` | `#0284C7` | `QUIZ` |
| 액티브/팀빌딩 | `#DCFCE7` | `#15803D` | `#22C55E` | `SURVIVAL` |
| 음악/미디어 | `#FFE4E6` | `#BE123C` | `#F43F5E` | `PICK` |

- 카테고리 카드에는 `data-palette`만 지정하고 색상값을 화면별로 다시 쓰지 않는다.
- Surface는 카드 아이콘과 활성 배경, Text/Icon은 텍스트와 아이콘, Accent는 진행선과 강조선에 사용한다.
- 상태 의미(성공, 경고, 오류)는 카테고리 색과 분리한다.

## 공통 사이드바 원칙

구현 기준은 `src/app/sidebar-nav.tsx`와 `sidebar-nav.module.css`다.

1. 사이드바는 목록 탐색이나 작업 공간 전환이 반복되는 화면에만 사용한다.
2. 정보 계층은 그룹과 보조 수준을 합쳐 최대 2단계까지만 허용한다.
3. 활성 항목은 배경, 텍스트 색, 오른쪽 강조선으로 동시에 표시한다. 색상만으로 상태를 전달하지 않는다.
4. 개수나 미완료 상태는 항목 오른쪽 배지에 표시한다.
5. 데스크톱 기본 폭은 240px 안팎이며 80px 아이콘 모드로 접을 수 있다.
6. 모바일에서는 가로로 긴 사이드바를 노출하지 않고, 현재 선택을 보여주는 접힌 패널로 시작한다.
7. 행동 유도 카드는 하단에 하나만 둔다. 주요 탐색 항목과 경쟁하지 않아야 한다.
8. 보조 수준은 연결선과 들여쓰기로 부모 관계를 보이되 더 깊게 중첩하지 않는다.

## 적용 범위

- 적용: `/games` 컬렉션·상황 탐색, `/items` 콘텐츠 상태·게임 유형 탐색.
- 보류: `/create`는 순차 입력 흐름, `/cuesheets`는 저장 목록, `/account`는 설정 항목이 적어 현재는 사이드바보다 단일 컬럼이 명확하다.
- `/admin`은 관리 영역이 게임 외 콘텐츠·사용자·운영 설정으로 늘어날 때 공통 사이드바를 적용한다. 현재 단일 대시보드에 강제로 붙이지 않는다.

## 토스·애플 참고 원칙

- 토스에서 가져온 것: 큰 한 문장, 넓은 여백, 얇은 구분선, 짧은 섹션 라벨과 핵심 콘텐츠의 분리, 빠르게 사라지는 내비게이션.
- 애플에서 가져온 것: 반투명 표면, 20px 전후 블러, 절제된 그림자와 움직임.
- 가져오지 않는 것: 브랜드 로고·카피·그래픽의 모사. 레크플러스의 파란색과 현장 운영 언어를 유지한다.
