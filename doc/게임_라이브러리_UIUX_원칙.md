# 게임 라이브러리 UI/UX 원칙

## 목표

게임을 찾기 위한 조작보다 실제 게임 정보가 먼저 눈에 들어오게 한다. 화면 크기가 달라져도 사용자는 현재 보고 있는 컬렉션, 검색 결과 수, 적용할 수 있는 조건, 게임 목록의 관계를 한 덩어리로 이해할 수 있어야 한다.

## 디자인 철학

1. **콘텐츠 우선**: 검색과 정렬은 콘텐츠를 돕는 도구이며 제목이나 게임 카드보다 강하게 보이지 않는다.
2. **관계 기반 그룹화**: 결과 수, 정렬, 검색, 빠른 조건처럼 같은 목록을 바꾸는 요소는 하나의 작업영역에 모은다.
3. **목적 있는 여백**: 큰 여백은 주요 구역 사이에서만 사용하고, 같은 과업 안의 요소는 짧고 일정한 간격으로 연결한다.
4. **정보 밀도의 단계적 축약**: 모바일은 데스크톱을 단순 적층하지 않는다. 결과 수와 정렬을 한 행에 두고, 검색과 빠른 조건을 그 아래에 배치한다.
5. **첫 화면의 성과**: 모바일 첫 화면에서 최소한 첫 게임 카드의 시작이 보여야 하며, 핵심 데이터인 인원·시간·진행 방식은 카드 안에서 빠르게 스캔할 수 있어야 한다.
6. **조작의 위계**: 행사 플랜 만들기는 주요 행동으로 유지하되 작은 화면에서는 화살표형 압축 버튼으로 바꾸고, 정렬과 초기화는 보조 행동의 크기와 대비를 갖는다.

## 이번 수정 범위

- 대형 제목과 상단 여백을 줄여 목록 진입 거리를 단축한다.
- 검색·정렬·결과 수·빠른 조건을 하나의 얕은 제어 패널로 통합한다.
- 정렬을 결과 수 옆의 작은 컨트롤로 이동한다.
- 모바일 순서를 `결과 수/정렬 → 검색 → 빠른 조건 → 게임 목록`으로 재배치한다.
- 모바일 컬렉션 선택기와 게임 카드의 높이, 내부 간격을 줄인다.

## 후속 적용 기준

- 같은 패턴의 목록 화면은 제어 패널 구조와 간격 토큰을 재사용한다.
- 새로운 필터를 추가할 때는 별도 행을 만들기 전에 기존 빠른 조건 또는 사이드바 그룹에 포함할 수 있는지 먼저 검토한다.
- 기능 추가 후 375px 모바일과 데스크톱에서 첫 카드 노출 위치, 가로 넘침, 키보드 포커스를 함께 검증한다.
