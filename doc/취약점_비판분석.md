# 레크마스터 취약점 비판적 분석
## — "데모는 되는데, 실제 MT에서 진짜 쓸까?"

> 지금까지 "기능이 작동하느냐"에 집중했다. 이제 냉정하게 묻는다:
> **진행자가 실제 MT 현장에서 이 앱을 켜고, 끝까지 쓰고, 다음에 또 열까?**
> 이 질문에 걸리는 취약점을 우선순위로 정리한다.

---

## 🔴 치명적 (이거 안 고치면 제품이 안 됨)

### C1. 콘텐츠 고갈 — 두 번째 MT에서 "또 이거네"
- **현실**: 초성퀴즈 문제 1개, 밸런스 9개, 만약에 6개… 실사용엔 턱없이 부족.
- **왜 치명적**: 같은 진행자가 3월 새터에서 쓰고, 5월 MT에서 또 열면 **똑같은 문제가 반복**됨. 리텐션이 여기서 죽는다.
- **더 깊은 문제**: "매번 새로운 게임 생성"이 이 앱의 핵심 가치인데, 풀이 작으면 그 약속이 거짓말이 됨.
- **개선**: 게임당 최소 30~50개로 확충 + 랜덤 소진 방식(한 세션에서 본 문제 재출제 방지) + 카테고리 다양화.

### C2. 진행자가 현장에서 "당황"하는 순간 대비 부족
- **현실**: 대본은 있지만, 게임을 **처음 하는 진행자가 룰을 제대로 이해했는지** 알 수 없음. 대본만 읽으면 참가자가 "그게 무슨 말이에요?" 할 수 있음.
- **왜 치명적**: 이 앱의 존재 이유가 "진행 실패 공포 제거"인데, 정작 룰 설명이 불충분하면 공포가 그대로.
- **개선**: 각 게임에 **"이렇게 진행하세요" 3단계 요약** + 예시 시연 + "자주 나오는 상황" 대처법.

### C3. 오프라인 대응 전무
- **현실**: MT 장소(펜션, 산속, 대형 버스)는 **와이파이·데이터가 약하거나 없음**. 근데 앱이 웹이라 네트워크 끊기면 먹통.
- **왜 치명적**: "현장에서 쓰는 도구"인데 현장에서 안 켜지면 끝. 진행자는 앱을 다시는 안 믿음.
- **개선**: 큐시트·게임 데이터를 **로컬에 캐싱**(PWA/localStorage), 오프라인에서도 진행 가능하게. 음악 등 네트워크 필요 기능만 온라인 표시.

## 🟠 심각 (사용자 이탈로 직결)

### S1. 데이터 휘발 — 새로고침하면 다 사라짐
- 만든 큐시트, 편성한 조, 진행 중이던 점수… **새로고침 한 번에 초기화**.
- 현장에서 폰 실수로 껐다 켜면 그동안 준 점수 다 날아감 → 대참사.
- **개선**: localStorage로 상태 영속화. 진행 중 상태 자동 저장·복구.

### S2. 개인전인데 점수판이 없음
- 팀전은 점수판 있는데 **개인전은 점수 추적 수단이 전무**. 개인전 서바이벌도 순위·벌칙자 기록이 필요.
- 결과 화면의 "MVP 민준 / 벌칙자 지훈"은 **하드코딩** — 실제로 아무 데이터랑 연결 안 됨.
- **개선**: 개인전용 참가자 리스트 + 개인 점수/생존 트래킹. 결과가 실제 데이터 반영.

### S3. 큐시트 진행 중 이탈·수정 불가
- 진행 시작하면 **게임 추가/삭제/순서변경 불가**. 현장은 유동적인데(시간 남거나 모자라거나) 대응 못 함.
- "이 게임 반응 별로다 스킵" or "시간 남으니 하나 더" 같은 즉석 대응 안 됨.
- **개선**: 진행 중에도 게임 스킵/추가/순서조정 가능하게. 구급상자 외에 정식 게임도 즉석 삽입.

### S4. 시간 관리가 형식적
- 타이머는 돌아가지만 **다음 게임으로 자동 안 넘어가고**, 시간 초과해도 아무 일 없음.
- 전체 진행이 목표 시간 대비 얼마나 밀렸는지 **누적 추적 안 됨**.
- **개선**: 전체 경과/잔여 시간 표시, 게임별 오버런 경고, "지금 페이스면 X분 초과" 안내.

## 🟡 개선 필요 (완성도·신뢰도)

### M1. 접근성 — 어두운 MT 현장 가독성
- 애플 라이트 테마는 예쁘지만 **어두운 곳에서 흰 화면은 눈부심**. 밤 MT엔 다크가 유리.
- 글씨가 진행자 기준으론 괜찮지만 폰을 멀리 들면 작을 수 있음.
- **개선**: 다크모드 토글, 진행 화면 글씨 크기 옵션.

### M2. 조 편성의 현실 괴리
- 이름 일일이 타이핑은 **40명이면 고역**. 현실에선 안 씀.
- 조별 인원이 안 맞을 때(홀수) 처리, 특정인 같은 조 방지(커플 갈라놓기) 같은 실전 니즈 없음.
- **개선**: 번호 배정을 기본으로, 이름은 선택. 조 불균형 자동 조정. (고급: 제약조건)

### M3. 게임 검수의 악용 가능성
- 커뮤니티 게임에 **비속어·부적절 콘텐츠** 자동필터가 "통과"라고 표시만 하지 실제 검사 로직 없음.
- 저작권 침해 문제(유명 게임 그대로 베끼기) 감지 없음.
- **개선**: 실제 금칙어 필터, 유사도 체크, 신고 기능.

### M4. 첫 사용자 온보딩 없음
- 처음 켜면 바로 "새 큐시트 만들기". **이 앱이 뭘 해주는지, 어떻게 쓰는지** 설명 없음.
- 데스크톱↔모바일 관계도 안 알려줌.
- **개선**: 첫 실행 3단계 온보딩 or 샘플 큐시트 제공.

## 🔵 전략적 취약점 (사업 관점)

### B1. "왜 이 앱이어야 하나" 방어 약함
- 유튜브에 "MT 게임 100선" 검색하면 다 나옴. **우리만의 결정적 차별점**이 아직 약함.
- 차별점 후보: ①검증된 순서(energy 곡선) ②현장 진행 콘솔 ③커뮤니티 게임. 근데 다 "있으면 좋은" 수준이지 "이것 때문에 깐다"가 없음.
- **개선 방향**: 하나를 뾰족하게. 예) "진행 중 실시간 콘솔"을 압도적으로 완성.

### B2. 바이럴 고리가 약함
- 공유 카드 하나로는 부족. 참가자가 "나도 써야지"가 되려면 **참가자 경험 자체**가 인상적이어야.
- "참가자 접속 0" 철학과 바이럴이 상충 — 참가자가 앱을 아예 안 만짐.
- **개선**: 결과 공유를 더 매력적으로 + 참가자가 QR로 결과 받아보기 등 최소 접점.

### B3. 수익 모델 부재
- 무료로 다 쓰면 뭘로 버나. 게임팩 유료? 프리미엄? 아직 설계 없음.
- **개선**: 프리(기본 게임) + 프리미엄(시즌팩, 무제한 커스텀, 음악연동) 구조 검토.

---

## 우선순위 실행 계획

**지금 당장 고칠 것 (이번 개선)**
1. **C1 콘텐츠 확충** — 게임 문제 대폭 늘리고 랜덤 소진 방식
2. **S1 데이터 영속화** — localStorage로 저장, 새로고침 생존
3. **S2 개인전 점수판 + 실제 결과 연동** — 하드코딩 제거
4. **S3 진행 중 게임 스킵/추가** — 현장 유동성 대응
5. **S4 시간 관리 강화** — 전체 경과/잔여, 오버런 경고

**다음 단계**
- C2 룰 설명 강화, C3 오프라인(PWA), M1 다크모드, M4 온보딩

**전략 논의 필요 (별도)**
- B1 차별점 뾰족하게, B3 수익모델

---

## 이번 개선의 핵심 관점
지금까진 "화면이 예쁘고 흐름이 이어지느냐"였다.
이번엔 **"현장에서 안 죽고, 데이터가 안 날아가고, 두 번째에도 열리느냐"** — 즉 **신뢰성과 지속성**에 집중한다.
