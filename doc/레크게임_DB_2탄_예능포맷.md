# 레크리에이션 게임 DB — 2탄: 예능 시그니처 포맷 이식판

> 신서유기·지구오락실·런닝맨 등에서 **실제로 빵 터졌던 게임 포맷**을 MT/모임용으로 이식.
> 방송의 *포맷(규칙)*만 참고하고, 문제·데이터는 전부 **오리지널로 새로 작성**해 저작권 안전.
> 방송 고유명(예: "삼장법사", "드래곤볼")은 앱에서 **자체 네이밍으로 치환**하는 것을 전제로 함.
>
> 태그 규칙은 1탄과 동일: phase / place / mode / 인원 / 소품

---

## 이번 탄의 핵심 발굴 (다른 앱엔 없는 무기)

방송에서 검증됐지만 기존 레크 앱들이 안 다루는 **"포맷형 게임"** 위주로 골랐다:

| 방송 원형 | 이식 게임명(제안) | 왜 강력한가 |
|---|---|---|
| 자네 지금 뭐하는 건가 | **"미션 임파서블"** | 폰이 즉석 개인미션 배정 → 폭소 유발, 준비물 0 |
| ○○을 지켜라 | **"수호대작전"** | 방어/약탈 구도, 팀전 최고 긴장감 |
| 브랜드 퀴즈 | **"이거 뭐야 퀴즈"** | 사진 한 장으로 무한 확장 |
| 줄줄이 말해요 | **"릴레이 폭탄"** | 이어말하기+탈락, 버스에서 최고 |
| 훈민정음(외래어 금지) | **"우리말 지킴이"** | 상시 벌칙 룰, 하루 종일 작동 |
| 시그널 퀴즈 | **"인트로 맞히기"** | 효과음/시그널로 저작권 우회 가능 |
| 빨간종이 파란종이 | **"운명의 쪽지"** | 심리전+복불복, 익명 재미 |
| 웃으면 죽는다 | **"포커페이스"** | 준비물 0, 어디서나 |
| 딸기 게임 | **"손병호 딸기"** | 지목+생존, 순위 자동 정렬 |

# E. 미션·순발력형 (예능 시그니처)

## 26. 미션 임파서블 (원형: 자네 지금 뭐하는 건가)
- **phase** icebreak/filler · **place** room/hall · **mode** solo · **인원** 4~20 · **소품** 없음
- **틀**: 앱이 각자에게 **제한시간 내 수행할 돌발 미션**을 랜덤 배정. 성공하면 포인트/면벌, 실패하면 벌칙. 미션이 황당할수록 웃김.
- **랜덤 생성**: 미션 풀에서 인원수만큼 랜덤 배정 + 제한시간(5~15분) 랜덤
- **방송 포인트**: 성공/실패가 극적으로 갈려서 리액션이 최고. 전원 실패도 웃음 포인트.

### 예시 미션 풀 (오리지널 · 순한맛)
- 5분 안에 아무나 3명에게 하이파이브 받기
- 옆 사람 웃기기 (3분 안에 성공)
- 지금부터 10분간 말끝마다 "~다냥" 붙이기
- 아무나 붙잡고 진심 어린 칭찬 30초
- 5분 안에 셀카 5장 찍기(각자 다른 사람과)
- 지금 이 방에서 파란색 물건 3개 찾아오기
- 10분간 다리 꼬지 않기(들키면 실패)
- 진행자 몰래 등 뒤에 포스트잇 붙이기
- 5분간 웃지 않기
- 아무 노래나 한 소절 완창하기
- 물 한 컵 원샷하고 "카~" 외치기
- 지목한 사람과 3분간 눈 안 마주치기

---

## 27. 수호대작전 (원형: ○○을 지켜라)
- **phase** main · **place** room/hall · **mode** team · **인원** 6~30 · **소품** 지킬 물건(과자 등)
- **틀**: 각자/각 팀이 **지정된 물건(간식)**을 받고, 제한시간 동안 뺏기지 않고 지키기. 동시에 남의 것 약탈 가능. 끝까지 지킨 사람만 그걸 먹음.
- **랜덤 생성**: 지킬 아이템 랜덤 배정 + 시간·규칙(접촉 금지 등) 랜덤
- **방송 포인트**: 배신·연합·기습이 나와서 스토리가 생김. MT 간식 걸면 몰입 폭발.
- **변형**: "○○을 이겨라"(각자 특기 종목으로 1:다 대결)

### 룰 프리셋 예시
- **클래식**: 손에서 놓으면 뺏김. 15분 사수.
- **매점런**: 뺏은 사람이 다 가짐. 무한 약탈.
- **스텔스**: 지정 시간에 알람 울림 → 그 순간 들고 있으면 벌칙.

---

## 28. 이거 뭐야 퀴즈 (원형: 브랜드 퀴즈)
- **phase** main · **place** hall(화면)/room · **mode** both · **인원** 4~50 · **소품** 화면
- **틀**: 사물/로고/음식/장소의 **일부만 확대**하거나 흐리게 보여주고 정체 맞히기. 순서대로 답하고 틀리면 상품 하나씩 감소(신서유기 룰).
- **랜덤 생성**: 이미지 풀 랜덤 + 표시방식(줌/블러/실루엣) 랜덤
- **앱 주의**: 실제 브랜드 로고는 상표권 이슈 → **일반 사물/음식/자연물** 위주 또는 자체 일러스트로.

### 예시 (텍스트 힌트형 · 사물)
| 정답 | 확대 힌트 | 추가 힌트 |
|---|---|---|
| 딸기 | 빨간 표면의 작은 씨앗들 | 겉에 씨가 박힘 |
| 리모컨 | 빨간 버튼 클로즈업 | 소파에서 자주 잃어버림 |
| 양파 | 반투명 껍질 층 | 썰면 눈물 |
| 지우개 | 하얀 모서리 | 필통 단골 |
| 콘센트 | 구멍 두 개 | 벽에 붙음 |
| 브로콜리 | 초록 몽글몽글 | 나무 닮은 채소 |

## 29. 릴레이 폭탄 (원형: 줄줄이 말해요 / 이어말하기)
- **phase** icebreak/main · **place** bus/room · **mode** both · **인원** 3~20 · **소품** 없음(★버스)
- **틀**: 주제 안에서 순서대로 이어 말하되, **앞사람이 말한 걸 다 복창한 뒤 새 항목 추가** (줄줄이 버전). 못 외우거나 3초 초과 시 탈락.
- **랜덤 생성**: 주제 풀 랜덤
- **방송 포인트**: 뒤로 갈수록 외울 게 쌓여서 긴장. 기억력 배틀.

### 예시 주제
"시장에 가면~ (물건)", "동물원에 가면~", "냉장고 속에는~", "MT에 챙길 것은~", "우리 과 특징은~", "여름 하면~"

### 변형: 끝말잇기 지옥
- 특정 글자 금지("ㅁ으로 끝나면 안 됨"), 3초 룰, 한 방 단어(뤼순 등) 금지

---

## 30. 우리말 지킴이 (원형: 훈민정음 게임)
- **phase** 상시(전체 세션 백그라운드) · **place** 전부 · **mode** both · **인원** 4~50 · **소품** 없음
- **틀**: 세션 내내 **외래어·영어 금지**. 걸리면 즉석 벌점/벌칙. 진행자가 랜덤 단속.
- **랜덤 생성**: 금지 규칙 랜덤(외래어 금지 / 특정 단어 금지 / 이름 부르기 금지 등)
- **앱 강점**: 백그라운드 타이머로 "지금부터 30분 외래어 금지!" 공지 + 적발 카운터
- **방송 포인트**: 게임 중이 아닌 **일상 대화에서 툭 걸리는** 게 핵심 재미. 하루 종일 작동.

### 금지 규칙 프리셋
- 외래어/영어 전면 금지
- 서로 이름 대신 별명만
- "네/아니오" 금지
- 손가락으로 사람 가리키기 금지

---

## 31. 인트로 맞히기 (원형: 시그널 퀴즈 / 냉삼 음악퀴즈)
- **phase** main · **place** room/hall(스피커) · **mode** both · **인원** 4~50 · **소품** 스피커
- **틀**: 짧은 **시그널/효과음/전주**를 듣고 정체(프로그램·상황·노래) 맞히기.
- **랜덤 생성**: 오디오 클립 풀 랜덤 + 재생 길이 랜덤
- **앱 주의**: 실제 방송 시그널·음원은 저작권 이슈 → **자체 제작 효과음**이나 **"이 소리는 뭘까"(생활 소음: 전자레인지·카톡·지하철 안내음 등, 직접 녹음)** 로 구성.
- **저작권 안전 변형**: "생활 소음 퀴즈" — 앱이 직접 녹음한 소리(라면 끓는 소리, 지퍼, 도어락 등) 맞히기.

### 예시 (생활 소음 · 앱 자체 녹음 대상)
전자레인지 종료음 / 카톡 알림 / 지하철 도착 안내 멜로디 / 라면 물 끓는 소리 / 키보드 타건 / 도어락 열림 / 자판기 동전 / 세탁기 완료음

---

## 32. 운명의 쪽지 (원형: 빨간종이 파란종이)
- **phase** finale/filler · **place** room · **mode** solo · **인원** 4~20 · **소품** 없음(앱 익명배분)
- **틀**: 앱이 각자에게 **익명으로 +점/-점 카드**를 나눠줌. 본인은 자기 것 못 봄(또는 남에게 몰래 배정). 합산해서 꼴찌가 벌칙.
- **랜덤 생성**: +/- 카드 비율 랜덤 배분
- **방송 포인트**: 누가 나에게 마이너스를 줬는지 모르는 심리전.
- **변형**: "천사와 악마" — 익명으로 서로 점수 주기

---

## 33. 포커페이스 (원형: 웃으면 죽는다)
- **phase** filler/finale · **place** room · **mode** solo · **인원** 3~15 · **소품** 없음
- **틀**: 지정된 한 명(또는 전원)이 **웃으면 탈락**. 나머지는 온갖 방법으로 웃기기. 마지막까지 참으면 승리.
- **랜덤 생성**: 웃기기 미션 카드(성대모사/개인기/표정) 랜덤 제공
- **앱 강점**: 카메라로 웃음 감지(옵션) 또는 진행자 수동 판정 + 타이머

### 웃기기 미션 카드 예시
- 가장 웃긴 표정 5초
- 아무 동물 울음소리
- 좋아하는 사람 이름 진지하게 부르기
- 무표정으로 "사랑합니다 고객님"
- 갑자기 슬픈 표정 짓기

---

## 34. 손병호 딸기 (원형: 딸기 게임 / 캐릭터 정하기)
- **phase** opening/finale · **place** room · **mode** solo · **인원** 4~15 · **소품** 없음
- **틀**: 순위·역할·벌칙자를 정하는 **생존형 지목 게임**. 손가락 접기(손병호)로 최후 생존자/최초 탈락자 결정 → 그 사람이 캐릭터/벌칙/진행자.
- **랜덤 생성**: "접어" 조건 랜덤 + 용도(순위정하기/벌칙자/팀장뽑기) 선택
- **앱 강점**: 인원·순위 자동 집계, "1등부터 꼴찌까지" 자동 정렬

### 용도별 프리셋
- 벌칙자 뽑기 / 첫 발표자 정하기 / 팀장 정하기 / 게임 순서 정하기 / 방 배정

---

## 35. 천지창조 (원형: 천지창조 게임)
- **phase** opening/icebreak · **place** room · **mode** both · **인원** 2~12 · **소품** 없음
- **틀**: 마주 보고 구령에 맞춰 **손가락 개수를 동시에 냄**. 합이 외친 숫자와 같으면 성공/손 내리기. 순발력+눈치.
- **변형**: "참참참", "손가락 텔레파시"(둘이 같은 개수 내면 성공)

---

## 36. 코끼리코 (원형: 코끼리코 돌고 신발 잡기)
- **phase** finale/filler · **place** hall/room · **mode** solo · **인원** 4~20 · **소품** 없음
- **틀**: 제자리에서 코끼리코로 N바퀴 돈 뒤 미션 수행(직선 걷기, 물건 잡기). 어지러워서 비틀거리는 게 재미.
- **랜덤 생성**: 회전수 + 미션 랜덤
- **앱 강점**: 회전 카운트 사운드 + 미션 표시. **벌칙 연계 최적.**

# F. 지목·토크 심화형

## 37. 폭탄 돌리기 딜레마 (원형: 자네~ + 폭탄)
- **phase** icebreak · **place** bus/room · **mode** solo · **인원** 4~15 · **소품** 없음(폰)
- **틀**: 폰을 돌리다 멈추는 사람이 **앱이 낸 질문에 솔직 답변** 또는 미니미션. TMI 유도.
- **랜덤 생성**: 질문/미션 풀 랜덤

### 예시 질문
- 여기서 제일 친해지고 싶은 사람?
- 최근 가장 창피했던 순간?
- 내 첫인상 솔직하게 물어보기(아무나 지목)
- 지금 배고픔 1~10 중?
- 오늘 MT 오면서 든 생각?

---

## 38. 인간 스피드 퀴즈 (원형: 특기자랑/스피드 종합)
- **phase** main · **place** room/hall · **mode** team · **인원** 6~40 · **소품** 없음
- **틀**: 여러 미니게임을 **연속 스테이지**로. 팀별 릴레이. (옷 빨리 갈아입기·동전 뒤집기·문자 빨리 보내기 등 방송 특기대회 포맷)
- **랜덤 생성**: 미니게임 풀에서 N개 랜덤 조합 → 토너먼트

### 미니게임 풀 예시 (준비물 최소)
동전 30초 최대한 뒤집기 / 폰으로 지정 문장 빨리 타이핑 / 한 발 오래 서기 / 숨 참기 / 초성 5개 빨리 맞히기 / 팔굽혀펴기 개수 / 눈 안 깜빡이기
