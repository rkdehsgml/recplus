# 레크리에이션 게임 DB — 3탄: 파티게임·순발력·챌린지 확장판

> 실내 파티게임, 술게임 순발력 계열(무알콜 버전으로 이식), 보드게임 파티 포맷, 틱톡 챌린지까지 확장.
> 규칙만 참고하고 데이터는 오리지널. 술=벌칙(물/미션)으로 치환해 **무알콜 MT·직장 워크샵에서도 사용 가능**하게 설계.
> 태그 규칙 동일: phase / place / mode / 인원 / 소품

# G. 릴레이·전달형

## 39. 그림 옮기기 (원형: 텔레스트레이션/그림 전달)
- **phase** main/icebreak · **place** room · **mode** team · **인원** 4~12 · **소품** 폰 or 종이+펜
- **틀**: 첫 사람이 제시어를 그림 → 다음 사람은 그림만 보고 단어 추측 → 다음 사람은 그 단어를 다시 그림… 릴레이. 마지막에 원본과 비교. **전달 과정의 왜곡이 폭소 포인트.**
- **랜덤 생성**: 제시어 풀 랜덤(그리기 어려운 추상어일수록 재밌음)
- **앱 강점**: 폰으로 그림→추측→그림 릴레이 자동 진행, 마지막에 전체 과정 슬라이드쇼

### 예시 제시어 (그림→왜곡 유발)
사랑니, 물멍, 출근길, 월요병, 짝사랑, 눈치게임, 새우깡, 불금, 숙취, 갑분싸, 방구석, 인생네컷, 치맥, 얼죽아, 등산왕

---

## 40. 리듬 술래 (원형: 딸기 게임/두부 게임 — 무알콜 이식)
- **phase** icebreak/finale · **place** room · **mode** solo · **인원** 5~15 · **소품** 없음
- **틀**: 박수 4박자 리듬에 맞춰 "○○ 몇 개!"를 외치며 사람 지목 → 지목된 사람이 박자 안에 받아야 함. 놓치면 술래(벌칙/벌점). 리듬 끊기면 아웃.
- **랜덤 생성**: 콜 단어(딸기/두부/사과 등) + 최대 숫자 랜덤
- **앱 강점**: 메트로놈 사운드로 박자 유지, 탈락자 자동 기록

### 진행 프리셋
- **딸기형**: "딸기 딸기 몇 개?" → 개수만큼 박수 후 다음 지목
- **두부형**: 앞뒤 사람이 모→다섯모, 숫자로 지목

---

## 41. 리듬 초성 (원형: 아이엠그라운드/베스킨라빈스31 — 무알콜)
- **phase** opening/icebreak · **place** bus/room · **mode** solo · **인원** 3~15 · **소품** 없음(★버스)
- **틀**: "아이엠그라운드 자기소개하기" 리듬에 맞춰 주제 단어를 리듬 깨지 않고 대기. 못 대거나 리듬 깨면 탈락.
- **변형**: 베스킨라빈스31 식 — 순서대로 숫자 세다 31 외치면 걸림(마지막 숫자 룰)
- **랜덤 생성**: 주제 + 리듬 속도 랜덤

### 주제 예시
이름/별명 릴레이, 좋아하는 음식, 가고 싶은 여행지, 동물, 감정 단어

---

## 42. 이어달리기 카테고리 (원형: 지하철 노선 게임/카테고리)
- **phase** icebreak/main · **place** bus/room · **mode** both · **인원** 3~20 · **소품** 없음
- **틀**: 하나의 카테고리 안에서 돌아가며 항목 대기. 중복·막힘·3초 초과 시 탈락. 카테고리가 소진될 때까지.
- **랜덤 생성**: 카테고리 풀 랜덤(고갈되기 적당한 크기로)
- **방송/술게임 포인트**: "지하철 2호선 역 이름 대기"처럼 아는 만큼 버티는 소진전.

### 카테고리 예시 (적당히 유한한 것)
2호선 지하철역 / 무지개 색 / 태양계 행성 / 라면 브랜드 / 편의점 이름 / 손흥민 소속팀 역사 / 한국 광역시 / 분식 메뉴 / 아이돌 그룹 / 웹툰 제목

---

## 43. 숫자 리듬 (원형: 뻔데기 게임)
- **phase** opening/filler · **place** bus/room · **mode** solo · **인원** 3~12 · **소품** 없음
- **틀**: "뻔-데기-뻔-데기…" 처럼 정해진 규칙(1-1-2-1-1-3…)으로 늘어나는 리듬을 순서대로. **타이밍 놓치면 탈락** (80%가 타이밍 실수).
- **랜덤 생성**: 콜 단어 페어 + 증가 규칙 랜덤
- **앱 강점**: 리듬 가이드 사운드, 다음 차례 하이라이트

---

# H. 두뇌·심리전형

## 44. 한 단어 스파이 (원형: 코드네임/라이어 심화)
- **phase** main · **place** room · **mode** team · **인원** 6~16 · **소품** 없음(앱 역할배분)
- **틀**: 팀에 제시어를 공유하되, **스파이 한 명만 다른 단어**를 받음. 각자 그 단어를 설명하는 **한 단어 힌트**를 냄. 토론으로 스파이 색출. 스파이는 안 들키게 묻어가기.
- **랜덤 생성**: 유사 단어 페어(다수/스파이) 랜덤 배분
- **앱 강점**: 역할 자동 배분, 힌트 라운드 타이머

### 다수/스파이 단어 페어 예시
| 다수 | 스파이 |
|---|---|
| 바다 | 수영장 |
| 커피 | 홍차 |
| 겨울 | 가을 |
| 영화관 | 연극무대 |
| 라면 | 우동 |
| 축구 | 농구 |
| 고양이 | 강아지 |
| 비행기 | 기차 |

---

## 45. 현미경 퀴즈 (원형: 줌인 카메라/가족오락관)
- **phase** main · **place** hall/room · **mode** both · **인원** 4~50 · **소품** 화면
- **틀**: 사물을 극단적으로 **확대**한 이미지를 보여주고, 서서히 줌아웃하며 정체 맞히기. 빨리 맞힐수록 고득점.
- **랜덤 생성**: 이미지 풀 랜덤 + 줌 레벨 랜덤
- **앱 주의**: 자체 촬영/일러스트 이미지 사용(저작권 안전)

### 확대 대상 예시 (일상 사물)
칫솔모, 벨크로, 오렌지 껍질, 스펀지, 지퍼, 키위 단면, 브로콜리, 골판지, 수건 올, 연필 심, 라면 면발, 양말 무늬

---

## 46. 찰떡 호흡 (원형: 텔레파시/이심전심 심화)
- **phase** icebreak/main · **place** room · **mode** team · **인원** 4~20(짝 단위) · **소품** 없음
- **틀**: 두 사람이 같은 질문에 **동시에 답을 외침**. 같으면 성공. "얼마나 통하나" 궁합 테스트. 커플·베프전.
- **랜덤 생성**: 답 갈리는 질문 풀 랜덤
- **변형**: 3명 이상 전원 일치 도전

### 질문 예시
- 무인도에 가져갈 것 하나?
- 치킨 시키면 부위는?
- 여행지 하면 국내 vs 해외?
- 라면에 계란 풀어 vs 안 풀어?
- 데이트는 영화 vs 맛집?

---

## 47. 소수의 선택 (원형: 마이너리티 게임/눈치싸움)
- **phase** main/icebreak · **place** room/hall · **mode** solo · **인원** 5~50 · **소품** 없음(앱 집계)
- **틀**: 모두 O/X 또는 A/B 질문에 답. **소수파(적은 쪽)에 선 사람만 생존**. 남들과 다르게 생각해야 이김. 마지막 1인까지.
- **랜덤 생성**: 5:5로 갈릴 만한 질문 풀 랜덤
- **앱 강점**: 실시간 투표 집계, 소수파 자동 판별, 생존자 트래킹

### 질문 예시 (반반 갈리게)
- 부먹 vs 찍먹
- 아침형 vs 저녁형
- 산 vs 바다
- 여름 vs 겨울
- 계획파 vs 즉흥파
- 강아지 vs 고양이
- 매운맛 vs 순한맛

# I. 챌린지·퍼포먼스형 (바이럴 직결)

## 48. 거울 댄스 (원형: 틱톡 댄스 챌린지)
- **phase** finale/main · **place** hall/room · **mode** both · **인원** 2~30 · **소품** 없음(음악)
- **틀**: 앱이 보여주는 간단 안무를 따라 추기. 팀별로 싱크로율 대결 or 릴레이로 동작 추가. **영상 촬영 → 인스타/틱톡 공유 직결.**
- **랜덤 생성**: 안무 시퀀스 랜덤 조합(4~8동작)
- **앱 강점**: 안무 가이드 애니메이션 + 카운트, **영상 저장/공유 = 바이럴 엔진.** (기획의 확산 메커니즘과 직결!)
- **저작권 주의**: 배경음악은 로열티프리 or 자체 트랙

### 동작 풀 예시 (누구나 따라할 수 있는)
손하트, 웨이브, 어깨털기, 포인트 안무, 점프, 돌기, 하트 뿅, 브이 포즈

---

## 49. N행시 배틀 (원형: 삼행시/사행시)
- **phase** icebreak/finale · **place** bus/room · **mode** both · **인원** 3~30 · **소품** 없음(★버스)
- **틀**: 앱이 랜덤 단어(이름·유행어)를 제시 → 각 글자로 시작하는 행시 짓기 → 투표로 베스트. **창의력+드립 폭발.**
- **랜덤 생성**: 운(제시어) 풀 랜덤 + 글자 수(2~5행) 랜덤
- **앱 강점**: 제출·투표 자동화, 베스트 하이라이트

### 제시어 예시
사랑, 치킨, 방학, 월요일, MT, 여행, 우정, 시험, 라면, (참가자 이름), 짝사랑, 새내기

---

## 50. 진실 or 도전 (원형: Truth or Dare — 글로벌 검증)
- **phase** finale/icebreak · **place** room · **mode** solo · **인원** 3~15 · **소품** 없음
- **틀**: 지목된 사람이 **진실(질문 솔직 답변)** 또는 **도전(미션 수행)** 선택. 앱이 질문/미션 랜덤 제공.
- **랜덤 생성**: 진실 질문 풀 + 도전 미션 풀 각각 랜덤
- **앱 주의**: 미션·질문 모두 **순한맛/건전**으로만. 수위 슬라이더로 조절 가능하게.

### 진실 질문 예시 (순한맛)
- 여기서 첫인상 제일 좋았던 사람?
- 최근 제일 크게 웃은 일?
- 인생 최대 흑역사 살짝만?
- 지금 배경화면 공개?
- 요즘 최애?

### 도전 미션 예시 (순한맛)
- 아무나 붙잡고 30초 칭찬
- 성대모사 하나
- 좋아하는 노래 후렴 부르기
- 웃긴 표정으로 셀카 찍기
- 옆사람과 3초 하트 포즈

---

## 51. 몸으로 이어 말해요 (원형: 고요속외침 + 몸으로말해요 하이브리드)
- **phase** main · **place** room/hall · **mode** team · **인원** 6~24 · **소품** 없음
- **틀**: 첫 사람이 제시어를 몸짓으로 다음 사람에게 → 그 사람이 본 대로 다음 사람에게 → 릴레이. 마지막 사람이 정답 외침. **전달 왜곡이 재미.**
- **랜덤 생성**: 동작 표현 제시어 풀 랜덤
- **앱 강점**: 릴레이 순서 표시, 원본/정답 비교 연출

### 제시어 예시
태권도, 요리사, 낚시, 발레, 복싱, 수영, 골프, 청소, 좀비, 로봇, 펭귄걸음, 김장

## 통합 정리: 1탄+2탄+3탄 = 총 51개 게임

### 특히 주목할 전략 게임 3종

**① 거울 댄스 (#48) — 확산 엔진 그 자체**
네가 정한 확산 메커니즘(인스타 스토리 공유)과 직결. 춤 영상은 공유 동기가 가장 강한 콘텐츠. **바이럴 설계의 핵심 무기.**

**② 그림 옮기기 (#39) / 몸으로 이어 말해요 (#51) — 폰 릴레이의 매력**
"참가자 접속 없이 폰 하나"라는 제약 안에서도, 폰을 옆으로 넘기는 릴레이 방식이면 접속 없이도 참여감을 줌. 결과물(왜곡된 그림)이 웃겨서 이것도 공유각.

**③ 소수의 선택 (#47) / 한 단어 스파이 (#44) — 대규모 대응**
50명 대강당에서도 굴러가는 몇 안 되는 포맷. 대규모 새터·개강총회 시나리오를 커버.
