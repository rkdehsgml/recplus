# 레크리에이션 게임 DB — 상세 룰 + 예시 문제 모음

> 앱 게임 DB 구축용 리서치 자료.
> 각 게임은 **틀(포맷)**로 정리했고, 예시 문제는 앱에 바로 넣을 수 있도록 **오리지널로 대량 작성**했다.
> (예능 포맷의 규칙은 참고하되, 문제·단어·질문 데이터는 저작권 문제 없이 자유 사용 가능한 새 데이터임)
>
> 표기 규칙
> - **phase**: opening(오프닝) / icebreak(아이스브레이킹) / main(메인승부) / finale(피날레·벌칙)
> - **place**: bus(이동/버스) / room(방·소규모) / hall(대강당·대형화면)
> - **mode**: solo(개인전) / team(팀전) / both
> - **인원**: 권장 최소~최대
> - **소품**: 필요 준비물 (없을수록 앱 친화적)

# A. 스피드·퀴즈형

## 1. 초성 퀴즈
- **phase** main · **place** bus/room/hall · **mode** both · **인원** 4~50 · **소품** 없음(화면 있으면 좋음)
- **틀**: 제시된 초성(자음)만 보고 단어를 맞힌다. 카테고리(영화/음식/장소/유행어 등)별로 풀을 나눠 랜덤 출제. 힌트 1~2개를 단계적으로 공개.
- **랜덤 생성 방식**: 단어 풀 → N개 랜덤 추출 → 초성 변환 → 힌트 자동 부여
- **진행 흐름**: 초성 제시 → 30초 카운트 → 못 맞히면 힌트 → 정답 공개
- **난이도 조절**: 힌트 개수, 글자 수, 카테고리 대중성

## 2. 인물 퀴즈 (3초 / 줌인)
- **phase** main · **place** hall(화면필수)/room · **mode** both · **인원** 4~50 · **소품** 화면·사진
- **틀**: 인물 사진을 3초만 보여주거나, 극단적으로 줌인한 상태에서 서서히 줌아웃하며 맞힌다.
- **랜덤 생성**: 인물 풀(연예인/캐릭터/역사인물) 랜덤 → 표시 방식(3초 or 줌) 랜덤
- **앱 주의**: 실제 연예인 사진은 초상권 이슈 → **자체 일러스트/실루엣/공개 도메인 인물**로 풀 구성 권장
- **변형**: "목소리 3초 듣고 맞히기", "특징 3개 듣고 맞히기"(사진 없이 텍스트 힌트만)

### 예시 문제 (텍스트 힌트형 · 사진 불필요 버전)

| 정답 | 힌트1 | 힌트2 | 힌트3 |
|---|---|---|---|
| 세종대왕 | 조선 4대 왕 | 만원권 지폐 | 한글 창제 |
| 이순신 | 조선 장군 | 거북선 | 백원 동전 |
| 아인슈타인 | 물리학자 | 혀 내민 사진 | E=mc² |
| 뽀로로 | 파란 펭귄 | 헬멧과 고글 | 노는 게 제일 좋아 |
| 산타클로스 | 빨간 옷 | 순록 썰매 | 12월 |
| 셜록 홈즈 | 탐정 | 파이프 | 왓슨 |
| 피카츄 | 노란 캐릭터 | 볼 빨간 | 전기 |

## 3. 노래 전주 퀴즈 (진프리즈)
- **phase** main · **place** room/hall(스피커 필요) · **mode** both · **인원** 4~50 · **소품** 스피커
- **틀**: 노래 전주(intro)만 몇 초 재생하고 제목/가수를 맞힌다. 빨리 맞힐수록 고득점.
- **랜덤 생성**: 곡 풀 랜덤 → 재생 길이(3/5/10초) 랜덤
- **앱 주의**: 실제 음원은 저작권 이슈 큼 → **가사 초성 힌트형** 또는 **멜로디 없이 "이 노래 가사 다음은?"** 텍스트 퀴즈로 대체 권장
- **저작권 안전 변형**: "떼창 퀴즈" — 유명 후렴 한 소절의 **다음 가사**를 텍스트로 맞히기(짧은 인용). 앱 내장 시엔 자작 응원가/직접 만든 멜로디 사용.

### 예시 (저작권 안전형 — 앱 자체 제작 응원가/캠프송 컨셉)
| 문제 | 정답 |
|---|---|
| (앱 자작 캠프송 A 전주 3초) | 우정의 노래 |
| (앱 자작 응원가 B 전주) | 승리의 함성 |

> 실제 서비스에선 저작권 자유 음원(로열티프리) 또는 자체 제작 트랙으로 풀 구성.

## 4. 스피드 게임 (한 단어 설명)
- **phase** main · **place** room/hall · **mode** team · **인원** 6~40(팀당 4~6) · **소품** 화면 or 카드
- **틀**: 출제자 한 명이 제시어를 보고, 말·몸짓으로 설명 → 팀원이 맞힌다. 제한시간 내 최대한 많이. "통과" 허용.
- **랜덤 생성**: 제시어 풀 랜덤 셔플 → 난이도별 배분
- **진행**: 60초 / 팀별 교대 / 맞힌 개수 집계

### 예시 제시어 풀 (오리지널, 난이도 표시)

**[쉬움]** 라면, 축구, 우산, 세탁기, 코끼리, 냉장고, 무지개, 자전거, 딸기, 눈사람, 선풍기, 거북이, 김밥, 놀이터, 텔레비전

**[보통]** 짝사랑, 아이스아메리카노, 지각, 다이어트, 방탈출, 롤러코스터, 첫눈, 소개팅, 모기, 캠핑, 시험기간, 멀미, 노래방, 택배, 알람

**[어려움/추상]** 질투, 데자뷰, 애매하다, 갑분싸, 손절, 눈치, 번아웃, 밀당, 오글거림, 현타, TMI, 낄끼빠빠, 워라밸, 국룰, 인싸

**[동작 특화 — 몸으로 말해요와 공유 가능]** 볼링, 수영, 요리, 낚시, 태권도, 셀카, 줄넘기, 기타연주, 양치질, 등산

## 5. 몸으로 말해요
- **phase** main/icebreak · **place** room/hall · **mode** team · **인원** 6~40 · **소품** 없음(화면 있으면 편함)
- **틀**: 말 없이 몸짓만으로 제시어 전달. (스피드 게임의 무음 버전)
- **랜덤 생성**: '동작 특화' 제시어 풀에서 랜덤
- **변형**: "이어 몸으로 말해요"(고요속의 외침처럼 릴레이 전달), "뒤로 전달"

### 예시 제시어 (동작으로 표현 쉬운 것 위주)
기타치기, 헤엄치기, 볼링, 골프스윙, 김치담그기, 다림질, 낚시, 태권도 발차기, 셀카찍기, 줄다리기, 요요, 훌라후프, 하품, 재채기, 좀비걷기, 로봇춤, 김밥말기, 계란후라이, 물풍선던지기, 눈싸움

## 6. 고요 속의 외침
- **phase** main · **place** room/hall · **mode** team · **인원** 6~30 · **소품** 헤드폰/이어폰(노이즈캔슬링)
- **틀**: 노래를 크게 튼 헤드폰을 쓴 사람에게, 옆사람이 입모양으로 단어 전달 → 릴레이. 마지막 사람이 맞히기.
- **랜덤 생성**: 입모양 구분 어려운 단어 풀 랜덤(웃음 유발 포인트)
- **진행**: 3~4명 릴레이, 100초 내 5개

### 예시 단어 (입모양 헷갈리는 것 = 재미 포인트)
| 단어 | 헷갈리는 오답(예상 삽질) |
|---|---|
| 고슴도치 | 코스모스, 곱슬머리 |
| 방울토마토 | 바구니, 마늘쫑 |
| 대나무숲 | 태권도, 개나리 |
| 냉장고 | 냄비, 병아리 |
| 형광펜 | 경찰서, 향수병 |
| 수제비 | 주전자, 슈퍼맨 |
| 우주비행사 | 부지런히, 무지개 |
| 코딱지 | 초콜릿, 로또 |
| 삼겹살 | 사각턱, 방게 |
| 훈민정음 | 부산정거장, 물음표 |

## 7. 이어 말하기 / 끝말잇기 변형
- **phase** icebreak/main · **place** bus/room · **mode** both · **인원** 3~20 · **소품** 없음(★버스에서 최고)
- **틀**: 주제 안에서 순서대로 단어를 잇거나, 끝말잇기. 못 대면 탈락/벌점.
- **변형 A. 주제 이어말하기**: "동물 이름만" 돌아가며. 3초 안에 못 대면 탈락.
- **변형 B. 앞말잇기**: 끝 글자가 아니라 앞 글자로 잇기 (난이도↑)
- **변형 C. 초성 릴레이**: 정해진 초성으로 시작하는 단어만

### 예시 주제 풀
동물 / 과일 / 나라 이름 / 가수 이름 / 음식 / 지하철역 / 브랜드 / 웹툰 제목 / 두 글자 단어만 / 받침 없는 단어만 / 'ㅅ'으로 시작하는 것

## 8. 초성 넌센스 · 꿀꿀 퀴즈
- **phase** icebreak/filler · **place** bus/room/hall · **mode** both · **인원** 2~50 · **소품** 없음
- **틀**: 말장난·넌센스 문제. 킬링타임(구급상자)용으로도 최적.

### 예시 (오리지널 넌센스)
| 문제 | 정답 |
|---|---|
| 세상에서 가장 뜨거운 과일은? | 천도(1000도)복숭아 |
| 소가 웃으면? | 우하하 |
| 개가 가장 좋아하는 계절은? | 개나리 필 때(봄) |
| 왕이 넘어지면? | 킹콩(King 꽝) |
| 병아리가 제일 좋아하는 약은? | 삐약 |
| 딸기가 회사에 지각한 이유? | 딸기잼(잼=지연) |
| 문을 열 수 없는 도시는? | 문(門) 닫힌 도시… 답: 대구(대구 두었다) |
| 눈이 녹으면? | 눈물 / (또는) 봄 |
| 가장 억울한 도형은? | 사각(死角) |
| 빵이 웃으면? | 빵긋 |

# B. 심리·토크형 (아이스브레이킹)

## 9. 밸런스 게임
- **phase** icebreak · **place** bus/room/hall · **mode** both · **인원** 2~50 · **소품** 없음(★만능)
- **틀**: 둘 중 하나 강제 선택. 선택 후 이유 토론 → 자연스러운 대화 유발.
- **랜덤 생성**: 질문 풀 랜덤 추출 → 난이도(가벼움/극단) 조절

### 예시 질문 (오리지널, 대량)

**[가벼움]**
- 평생 치킨만 vs 평생 피자만
- 여름만 있는 세상 vs 겨울만 있는 세상
- 하늘을 나는 능력 vs 투명해지는 능력
- 아침형 인간 vs 저녁형 인간
- 산으로 여행 vs 바다로 여행
- 라면은 꼬들 vs 퍼진
- 탕수육 부먹 vs 찍먹
- 민초 좋아 vs 민초 싫어
- 강아지상 vs 고양이상
- 여행은 계획파 vs 즉흥파

**[중간·현실]**
- 월급 두 배 야근 많음 vs 월급 그대로 칼퇴
- 연애 많이 짧게 vs 한 번 오래
- 카톡 읽씹 vs 안읽씹
- 친구랑 여행 vs 혼자 여행
- 돈 많고 시간 없음 vs 시간 많고 돈 없음
- 과제 몰아서 vs 미리미리
- 단톡방 알림 다 켬 vs 다 끔

**[극단·과몰입]**
- 전 애인 기억 삭제 vs 첫사랑 다시 만남
- 평생 존댓말만 vs 평생 반말만
- 모든 사람이 내 속마음 들림 vs 내가 모두 속마음 들림
- 미래 하루 미리 봄 vs 과거 하루 되돌림
- 3일 안 잠 vs 3일 안 먹음

**[MT·대학 특화]**
- 1교시 전공 vs 6교시 교양
- 조별과제 다 내가 함 vs 잠수 조원과 반반
- 새터 가서 밤샘 vs 일찍 잠
- 교수님과 밥 vs 혼밥
- MT 총무 맡기 vs 회비 두 배 내기

## 10. 과몰입 밸런스 토크
- **phase** icebreak · **place** room/hall · **mode** both · **인원** 4~30 · **소품** 없음
- **틀**: 밸런스 게임의 스토리 버전. 구체적 상황을 길게 깔고 선택 → 과몰입 토론.
- **랜덤 생성**: 시나리오 풀 랜덤

### 예시 시나리오 (오리지널)
1. "짝사랑하던 사람이 고백했다. 근데 내일 이민 감. 사귄다 vs 안 사귄다"
2. "복권 1등 당첨. 근데 당첨금 받으려면 전교생 앞에서 아무 노래나 완창. 받는다 vs 포기"
3. "타임머신 1회권. 과거의 흑역사 1개 지우기 vs 미래 로또번호 1개 알기"
4. "소개팅 상대가 완벽한데 씹는 소리가 엄청 큼. 만난다 vs 안 만난다"
5. "친구가 내 비밀을 지켜주는 대신, 매달 치킨 한 마리 요구. 준다 vs 비밀 공개"

## 11. 이심전심 (같은 답 맞추기)
- **phase** icebreak/main · **place** room/hall · **mode** team · **인원** 4~30 · **소품** 종이·펜 or 화면
- **틀**: 같은 질문에 각자 답을 적고, 팀원과 답이 겹치면 득점. "얼마나 통하나" 확인.
- **랜덤 생성**: 열린 질문 풀 랜덤
- **변형**: 두 명이 동시에 답 외치기(찰떡궁합 테스트)

### 예시 질문 (답이 갈리도록 설계)
- 치킨 하면 떠오르는 부위는?
- 초록색 하면 떠오르는 것은?
- 여름 하면 생각나는 한 단어?
- 유명한 가수 한 명?
- 분식집 대표 메뉴는?
- 우리 과 하면 떠오르는 것?
- 남자/여자 이름 흔한 것 하나?
- 놀이공원 하면?
- 겨울 간식 하나?
- 아침에 제일 먼저 하는 것?

- **틀**: 이마에 붙은(또는 폰에 뜬) 단어를 본인만 모름. 질문(예/아니오)으로 정체 추리.
- **랜덤 생성**: 인물/사물/직업 풀 랜덤
- **폰 활용**: 폰을 이마에 대면 화면에 단어 표시(헤이즈업 방식)

### 예시 정체 풀

# C. 순발력·몸풀기형 (오프닝)

## 15. 청개구리 게임 (반대로 하기)
- **phase** opening · **place** room/hall · **mode** both · **인원** 4~50 · **소품** 없음
- **틀**: 진행자 지시의 **반대로** 행동. "손 올려"→내려야 함. 틀리면 탈락.
- **변형**: 청개구리 가위바위보(지는 사람이 이김)
- **진행**: 속도 점점 빠르게

### 예시 지시어 세트
올려/내려, 앉아/일어서, 웃어/울어, 박수/멈춰, 왼쪽/오른쪽, 크게/작게, 만세/차렷

---

## 16. 눈치 게임
- **phase** opening/filler · **place** room/hall · **mode** solo · **인원** 4~30 · **소품** 없음
- **틀**: 순서 없이 아무나 1부터 숫자를 외침. 동시에 외치면 그 사람들 탈락. 마지막까지 살아남기 or 꼴찌가 벌칙.
- **변형**: 숫자 대신 단어(과일/동물)

## 17. 369 / 박수 게임
- **phase** opening · **place** bus/room · **mode** solo · **인원** 3~15 · **소품** 없음(★버스)
- **틀**: 순서대로 숫자를 세되 3·6·9에서 박수. 틀리면 벌점.
- **변형**: 3·6·9의 배수마다 박수 횟수 늘리기, 특정 숫자 금지어

---

## 18. 이미지 가위바위보
- **phase** opening · **place** hall/room · **mode** team · **인원** 10~50 · **소품** 없음
- **틀**: 두 팀이 호랑이/사람/총 중 하나를 동작+함성으로 동시에 표현. 호랑이>사람, 사람>총, 총>호랑이. 팀 전체가 합을 맞춰야 해서 단합용.

## 19. 모여라 게임
- **phase** opening/icebreak · **place** hall · **mode** solo · **인원** 15~100 · **소품** 없음
- **틀**: 진행자가 "○명!" 외치면 그 인원수로 뭉치기. 못 낀 사람 탈락. 대규모 아이스브레이킹 최강.
- **변형**: "생일 같은 달끼리", "MBTI 같은 사람끼리" 등 조건 모여라

## 20. 텔레파시 손병호 게임

- **틀**: 손가락 5개 편 상태에서 "○○인 사람 접어" → 해당되면 접기. 다 접으면 탈락(또는 벌칙). 서로 알아가기.

### 예시 "접어" 조건

- 오늘 지각한 사람 접어
- 이 중에 짝사랑 있는 사람 접어

- 자취하는 사람 접어
- 새내기 접어

# D. 벌칙·긴장형 (피날레)

## 21. 벌칙 룰렛
- **phase** finale · **place** room/hall · **mode** both · **인원** 2~50 · **소품** 없음(앱 화면)
- **틀**: 화려한 애니메이션 룰렛으로 벌칙자 또는 벌칙 내용 랜덤 선정.
- **랜덤 생성**: 벌칙 풀 + 참가자 명단 랜덤 배정
- **앱 강점**: 햅틱+사운드로 긴장감 연출

### 예시 벌칙 풀 (수위별)
**[가벼움]** 애교 3종세트, 성대모사 하나, 옆사람 칭찬 10초, 웃긴 표정 5초, 유행어 외치기, 아이돌 댄스 한 소절
**[중간]** 물 원샷, 벌칙송 완창, 아무나 지목해 러브샷(음료), 다음 게임 진행자 되기, 다음 코스 설거지
**[벌칙 아이디어 — 순한맛만]** 이마에 딱밤 대신 별점 주기, 팀 간식 사오기, 나만의 흑역사 하나 공개

## 22. 시한폭탄 (폭탄 돌리기)
- **phase** finale/filler · **place** room · **mode** solo · **인원** 4~20 · **소품** 없음(폰=폭탄)
- **틀**: 폰을 폭탄 삼아 돌리며 문제 답하기. 랜덤 시점에 "폭발"(진동+굉음). 들고 있던 사람 벌칙.
- **랜덤 생성**: 폭발 타이머 랜덤(10~40초) + 돌리는 동안 낼 미니 문제
- **앱 강점**: 진동 모터 극대화, 카운트다운 사운드

### 폭탄 도는 동안 낼 미니 문제 예시
"'ㄱ'으로 시작하는 음식 하나 말하고 넘기기" / "옆사람 이름 부르고 넘기기" / "동물 하나 말하고 넘기기" / "숫자 이어세며 넘기기"

## 23. 복불복 사다리

## 24. 마피아 (라이어)
