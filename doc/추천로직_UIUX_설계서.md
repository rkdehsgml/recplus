# 게임 추천 로직 & UI/UX 설계서
## — "최신 느낌 나는 레크 진행 앱" 만들기

> 51개 게임 DB를 **어떻게 추천하고, 어떻게 보여줄 것인가.**
> 2026 앱 디자인 트렌드를 우리 맥락(레크 진행 툴)에 맞게 취사선택해 설계.

---

# PART 1. 게임 추천을 어떻게 할 것인가

## 1-1. 추천의 3층 구조

단순 랜덤이 아니라 **3개 층위**로 추천 품질을 만든다.

```
[1층] 규칙 기반 필터링  — 장소·인원·시간으로 "가능한 게임"만 남김 (하드 필터)
[2층] 흐름 기반 배치    — energy 곡선으로 "순서"를 만듦 (기승전결)
[3층] 최신성 레이어     — 트렌드·계절·신상 게임을 위로 끌어올림 (신선함)
```

1층·2층은 앞서 정한 "슬롯 채우기" 로직 그대로. **3층이 이번에 추가되는 핵심** — "이 앱은 최신 감각이 있다"는 인상을 만드는 층.

---

## 1-2. [3층] 최신성 레이어 — "최신 느낌"의 정체

"최신 느낌"은 화려한 UI가 아니라 **콘텐츠가 지금 이 순간과 연결돼 있다는 감각**에서 나온다. 세 가지 장치:

### ① 시즌/이벤트 태그
게임·문제 데이터에 `season` 태그를 달아, 그 시기에 맞는 걸 자동으로 상단 노출.
- 3월 새터 시즌 → "새내기 아이스브레이킹" 큐레이션 자동 등장
- 연말 → "종강총회 특집", 밸런스 게임에 "올해의 순간" 질문
- 예: 밸런스 게임 질문 풀에 `#2026신년`, `#벚꽃시즌` 태그 → 시기별 우선 노출

### ② 트렌드 문제팩 (살아있는 콘텐츠)
초성퀴즈·N행시·밸런스 게임의 **문제 풀을 주기적으로 갱신**. 이게 "죽은 앱 vs 살아있는 앱"을 가름.
- "이번 달 유행어 초성퀴즈", "2026 밈 밸런스 게임"
- 서버 없이도 가능: **앱 업데이트 시 JSON 문제팩만 교체** (기획서의 모듈화 지침과 일치)
- 사용자 인식: "어? 이 앱 요즘 유행어도 아네" → 최신성 체감

### ③ "지금 뜨는 게임" 섹션
다른 진행자들이 최근 많이 고른 게임을 보여줌(로컬 집계 or 간단 카운터).
- "이번 주 새터에서 가장 많이 한 게임 TOP 3"
- 사회적 증거(social proof) → 선택 부담 감소 + 트렌드감

## 1-3. 추천 카드의 정보 설계

각 게임을 추천할 때 보여줄 정보. **"왜 이걸 추천하는지"가 보여야 신뢰가 생김.**

```
┌─────────────────────────────┐
│ 🔥 수호대작전          15분   │  ← 이름 + 예상 소요
│ 팀전 · 준비물: 간식          │  ← 핵심 조건 한 줄
│ "이 타이밍에 텐션 최고조"     │  ← 추천 이유(에너지 곡선 근거)
│ 👥 지난주 새터 인기 1위       │  ← 최신성/사회적 증거
│ [미리보기]        [교체 ⇄]   │  ← 액션
└─────────────────────────────┘
```

- **추천 이유 한 줄**이 핵심 차별점. 경쟁 앱/블로그엔 "그냥 게임 목록"만 있음.
- 이유 문구는 energy 곡선 위치에서 자동 생성: 오프닝="가볍게 시선 집중", 메인="본격 승부욕 자극", 피날레="긴장감 최고조"

# PART 2. UI/UX 설계 — "최신 느낌"을 만드는 법

## 2-0. 대전제 — 우리한테 맞는 트렌드만 고른다

2026 트렌드 조사 결과 중, **레크 진행 앱에 실제로 필요한 것만** 취사선택:

| 트렌드 | 채택? | 이유 |
|---|---|---|
| **다크 모드 기본** | ✅ 필수 | 어두운 MT 현장에서 눈부심 방지 (기획서 지침과 일치) |
| **제스처 우선 내비** | ✅ 채택 | 큐시트 넘기기=스와이프, 진행 중 한 손 조작 |
| **마이크로 인터랙션** | ✅ 핵심 | 정답/오답 버튼 햅틱+애니메이션 = "타격감" |
| **글래스모피즘(부분)** | ✅ 절제 사용 | 오버레이 카드(구급상자, 룰렛)에만 |
| **엄지 최적화 레이아웃** | ✅ 필수 | 진행자가 한 손으로 폰 들고 조작 |
| **AI 개인화** | 🔶 부분 | 추천 로직에만, UI엔 과함 |
| **3D/공간감** | ❌ 제외 | 무겁고 로컬 앱에 부담, 산만 |
| **AR** | ❌ 제외 | 우리 시나리오와 무관 |
| **음성 UI** | ❌ 제외 | 시끄러운 현장에서 무용 |

**결론: "다크 퍼스트 + 강한 햅틱/모션 + 엄지 조작 + 절제된 글래스"** 4개 축.
트렌드를 다 넣으면 산만해짐. 이 앱의 정체성(현장에서 빠르게)에 맞는 것만.

## 2-1. 디자인 시스템

### 컬러 (다크 퍼스트)
```
배경:      #0A0A0F (near-black, 순수 검정 아님 = 세련됨)
서피스:    #16161F (카드 배경)
서피스2:   #1E1E2A (떠있는 요소)

액센트(메인):  #FFE14D (네온 옐로우) — 정답/CTA
액센트(경고):  #FF4D6D (네온 핑크레드) — 오답/벌칙
액센트(포인트): #6C5CE7 (일렉트릭 퍼플) — 최신감/하이라이트
성공:         #4DFFA6 (민트 그린)

텍스트:    #FFFFFF (주), #A0A0B0 (보조)
```
> 순수 검정(#000) 대신 near-black + 채도 높은 네온 액센트 = 2026 감각.
> 퍼플을 "최신성 컬러"로 써서 신상/트렌드 뱃지에 활용.

### 타이포그래피
```
디스플레이: Pretendard ExtraBold, 34pt — 게임 이름, 타이머
제목:      Pretendard Bold, 24pt
본문:      Pretendard Medium, 17pt
대본(현장): Pretendard SemiBold, 22pt+ — 멀리서도 읽힘 (기획서: 1.5배 크게)
```
> Pretendard = 한글 앱 표준, 깔끔+현대적. 영문 혼용 자연스러움.
> 현장 대본만 예외적으로 크게 (진행자가 폰 멀리 들어도 읽힘).

### 모서리 & 깊이
```
카드 radius: 20px (넉넉한 라운드 = 2026 부드러운 감각)
버튼 radius: 16px
그림자: 색이 있는 그림자(colored shadow) — 액센트 컬러 20% 오파시티
        예: 옐로우 버튼 아래 옐로우빛 글로우
```
> 검정 그림자 대신 **컬러 글로우** = 네온/게이밍 감성, 최신 앱 시그니처.

## 2-2. 화면별 설계

### [화면 1] 홈 — 첫인상이 "최신"을 결정
```
┌─────────────────────────────┐
│  안녕하세요 👋               │
│  오늘은 어떤 모임인가요?      │  ← 대화형 인사(개인화 느낌)
│                             │
│  ┌───────────────────────┐  │
│  │  ✨ 새 큐시트 만들기    │  │  ← 퍼플 글로우, 가장 크게
│  └───────────────────────┘  │
│                             │
│  🔥 지금 뜨는 게임           │  ← 최신성 섹션(가로 스크롤)
│  [수호대작전][N행시][거울댄스]│
│                             │
│  📁 저장된 큐시트            │  ← 재사용(리텐션)
│  · 25 컴공 새터  · 동아리 MT │
└─────────────────────────────┘
```
- **"지금 뜨는 게임" 가로 스크롤**이 최신성의 첫 신호.
- 대화형 문구("어떤 모임인가요?")로 딱딱한 툴이 아닌 느낌.
- 저장된 큐시트 = 돌아올 이유.

### [화면 2] 셋업 마법사 — 3스텝, 풀스크린 전환
```
스텝 1/3   어디서 하나요?
  [🚌 이동중]  [🏠 방·소규모]  [🎤 대강당]   ← 큰 아이콘 카드

스텝 2/3   몇 명이서?
  [슬라이더: 5 ─●──────── 100]
  [개인전 / 팀전] 토글

스텝 3/3   얼마나?
  [30분] [60분] [90분] [직접입력]
```
- 한 스텝 = 한 화면(풀스크린). 스와이프로 넘김(제스처).
- **진행 인디케이터**(1/3, 2/3) 상단에 얇게 → 부담 감소.
- 선택 시 즉각 햅틱 + 카드 팝 애니메이션 = 마이크로 인터랙션.

### [화면 3] ★큐시트 결과 — 제품의 심장★
```
┌─────────────────────────────┐
│  완성! 60분 큐시트 🎉         │  ← 생성 완료 축하 모션
│  ┌──────────────────────┐   │
│  │ 1 리듬초성    5분  🟢 │   │  ← 타임라인 카드(드래그로 순서변경)
│  │   가볍게 시선 집중     │   │
│  ├──────────────────────┤   │
│  │ 2 밸런스게임  15분 🟡 │   │  ← energy를 색 점으로 시각화
│  │   자연스러운 대화 유도  │   │     🟢낮음 🟡중간 🔴최고조
│  ├──────────────────────┤   │
│  │ 3 수호대작전  25분 🔴 │   │
│  │   본격 승부, 텐션 최고 │   │
│  ├──────────────────────┤   │
│  │ 4 거울댄스    10분 🟣 │   │  ← 🟣=공유각 게임 표시
│  │   피날레 + 인증샷      │   │
│  └──────────────────────┘   │
│  [진행 시작 ▶]  [자료 추출]   │
└─────────────────────────────┘
```
- **energy 곡선을 색 점으로 시각화** → "이 순서엔 이유가 있다"가 한눈에.
- 카드 **드래그로 순서 변경**, 좌스와이프로 **교체**, 탭으로 **미리보기**.
- 상단에 미니 그래프로 텐션 흐름(🟢→🟡→🔴→🟣) 보여주면 "기승전결" 설득력 폭발.
- 생성 순간 **축하 모션**(컨페티/글로우) = 감정적 보상.

### [화면 4] MC 대시보드 — 현장 진행 (엄지 최적화)
```
┌─────────────────────────────┐
│ 수호대작전        ⏱ 12:34    │  ← 게임명 + 큰 타이머
│ ─────────────────────────── │
│                             │
│  [대본 프롬프터 - 큰 글씨]    │  ← 읽기만 하면 되는 대본
│  "자, 각자 받은 간식을..."    │
│  [반응없을때] [점수차날때]     │  ← 상황별 멘트 전환 탭
│                             │
│ ┌─────┬─────┬─────┬─────┐   │
│ │딩동댕│ 땡 │ 긴장 │환호 │   │  ← 사운드보드(엄지 닿는 하단)
│ └─────┴─────┴─────┴─────┘   │
│ ┌───────────┬───────────┐   │
│ │ A팀  +10  │ B팀  +10  │   │  ← 스코어보드
│ │  30  -10  │  20  -10  │   │
│ └───────────┴───────────┘   │
│              [다음 게임 →]    │  🚑(구급상자 항상 우상단)
└─────────────────────────────┘
```
- **하단 1/3에 모든 조작 버튼 집중** = 엄지존(thumb zone). 한 손 진행.
- 정답 버튼 = 옐로우 글로우 + 강한 햅틱 + "딩동댕" 사운드 (타격감).
- 오답 = 핑크레드 진동 + 화면 살짝 흔들림.
- 구급상자(🚑)는 항상 우상단 고정 → 돌발 상황 즉시 대응.

### [화면 5] 결과/공유 — 바이럴 엔진
```
┌─────────────────────────────┐
│   🏆 오늘의 MVP               │
│   ┌───────────────────┐     │
│   │                   │     │  ← 예능 자막st 카드
│   │   [닉네임] 님       │     │     (스토리 규격 9:16)
│   │   🥇 최종 우승!     │     │
│   │   벌칙자: [닉네임]   │     │
│   │                   │     │
│   │  #25컴공새터        │     │
│   └───────────────────┘     │
│   [📸 스토리 공유]  [저장]     │  ← 인스타 직접 공유
└─────────────────────────────┘
```
- **인스타 스토리 9:16 규격**으로 결과 카드 자동 생성.
- 예능 자막 폰트st(굵은 아웃라인, 네온) → 공유 욕구 자극.
- 해시태그 자동(#○○새터) → 검색 노출 + 바이럴.
- **이게 "참가자가 앱을 알게 되는" 유일한 접점.** 확산의 핵심.

## 2-3. "최신 느낌"을 만드는 디테일 5가지

실제로 사용자가 "오 이 앱 좀 하네" 느끼는 지점은 큰 구조보다 **작은 순간들**이다.

1. **로딩=생성 연출**: 큐시트 생성 시 "게임 조합 중..." 스켈레톤 + 카드가 하나씩 슬라이드인. 즉시 뜨는 것보다 "AI가 짜주는" 느낌.
2. **햅틱 언어**: 정답(똑), 오답(드르륵), 룰렛(점점 빨라지는 진동), 폭탄(폭발 진동). 촉각으로 상태 전달.
3. **컬러 글로우**: 버튼마다 색 그림자 → 정적인 화면에 생기.
4. **스프링 애니메이션**: 카드 등장/전환에 통통 튀는 스프링 이징 → 장난감 같은 재미.
5. **빈 상태(empty state)도 예쁘게**: 저장된 큐시트 없을 때 "첫 큐시트를 만들어보세요" 일러스트 → 방치된 느낌 제거.

## 2-4. 안티패턴 — 이건 하지 말 것

- ❌ 트렌드 욕심(3D·AR·음성) → 무겁고 산만, 로컬 앱 정체성 붕괴
- ❌ 과한 글래스모피즘 → 현장 가독성 저하 (오버레이에만 절제)
- ❌ 작은 글씨 → 진행자가 못 읽음. 현장 요소는 무조건 크게
- ❌ 깊은 메뉴 구조 → 현장에선 2탭 안에 모든 게 끝나야 함
- ❌ 밝은 배경 → 어두운 MT 현장에서 눈부심

# PART 3. 요약 — 이 설계가 주는 것

| 목표 | 해결 장치 |
|---|---|
| **최신 느낌** | 트렌드 문제팩 갱신 + 시즌 태그 + "지금 뜨는 게임" + 네온/글로우 다크 UI |
| **좋은 서비스 인상** | 추천 이유 명시 + energy 곡선 시각화 + 생성 연출 |
| **현장 실용성** | 엄지존 레이아웃 + 강한 햅틱 + 큰 대본 + 구급상자 |
| **바이럴** | 9:16 결과 카드 + 인스타 직접 공유 + 해시태그 |
| **리텐션** | 저장된 큐시트 + 시즌 콘텐츠 + 지금 뜨는 게임 |

> "트렌드 문제팩 + 추천 이유 시각화"로 최신·전문성을 주고,
