# 게임 현실 적합성 재분석
## — "방송 검증 × 진행자 혼자 굴릴 수 있는가"로 냉정하게 재평가

> 앞서 모은 51개를 다시 본다. 태그가 맞는다고 현실 레크에 적합한 건 아니다.
> **두 개의 엄격한 기준**으로 재평가:
> 1. **방송 검증**: 신서유기·지구오락실에서 실제로 반복 사용되며 재미가 검증됐는가
> 2. **현장 실현성**: 진행자 혼자, 특별한 준비물 없이, 폰 하나로 굴릴 수 있는가

---

## 등급 정의

| 등급 | 의미 | 처리 |
|---|---|---|
| **S** | 방송 검증 + 준비물 0 + 진행 쉬움 | **MVP 최우선 탑재** |
| **A** | 방송 검증 or 대중적 + 진행 쉬움 | 정식 버전 탑재 |
| **B** | 재밌지만 준비물·세팅 부담 있음 | 조건부(준비물 안내) 탑재 |
| **C** | 현실 레크 부적합 / 진행 어려움 | **일단 제외** |

---

## S등급 — 방송 검증 + 즉시 실행 (MVP 코어)

이것들이 신서유기·지구오락실에서 **반복적으로 나오고 항상 터진** 게임들. 무조건 우선.

| 게임 | 방송 출처 | 왜 S인가 |
|---|---|---|
| **카테고리 초성 퀴즈** | 지락실·신서유기 단골 | 지락실 시그니처. 폰에 초성만 띄우면 끝. 무한 확장 |
| **인물 퀴즈** | 신서유기 전 시즌 | 유서 깊은 검증 게임. 사진/힌트만 있으면 됨 |
| **청개구리 가위바위보** | 지락실 신상 대표 | 준비물 0, 룰 3초 설명, 대규모 OK |
| **랜덤 플레이 댄스** | 지락실 신상 대표 | 음악만 있으면 됨. 바이럴 직결(영상) |
| **몸으로 말해요** | 지락실·신서유기 | 세계적 검증(차라데). 폰 제시어만 |
| **이어 말하기(줄줄이)** | 신서유기 단골 | 준비물 0, 버스에서 최고 |
| **밸런스 게임** | 전 예능 공통 | 질문만 있으면 됨. 대화 유발 최강 |
| **눈치 게임** | 국민 게임 | 룰 초간단, 어디서나 |

> **8개 전부 "폰에 뭔가 띄우기 or 룰 설명만"으로 끝.** 진행자 부담 0. 이게 MVP 코어.

## A등급 — 대중 검증 + 진행 쉬움 (정식 탑재)

| 게임 | 근거 | 비고 |
|---|---|---|
| 스피드 퀴즈(한 단어 설명) | 특기대회·가족오락관 | 팀전, 화면 있으면 좋음 |
| 초성 넌센스/꿀꿀퀴즈 | 킬링타임 국민 | filler 최적 |
| 만약에 / 가정 질문 | 토크 국민 | 버스 최적 |
| 벌칙 룰렛 | 필수 유틸 | 앱 애니메이션 강점 |
| 시한폭탄 돌리기 | 신서유기(폭탄알람) | 햅틱 강점 |
| 손병호 게임 | 국민 게임 | 지목/순위 유틸 |
| 369 게임 | 국민 게임 | 버스 최적 |
| 마피아/라이어 | 국민 게임 | 앱 역할배분 강점 |
| N행시 배틀 | 삼행시 국민 | 창의력, 투표 |
| 이심전심(같은 답) | 가족오락관·커플예능 | 팀 궁합 |
| 브랜드/사물 퀴즈(→"이거 뭐야") | 신서유기 단골 | 상표 회피 필요 |
| 왕게임 | 국민(순한맛만) | 수위 관리 필수 |

---

## B등급 — 재밌지만 준비물/세팅 부담 (조건부 탑재)

준비물이나 세팅이 필요해서, **앱이 "이건 ○○가 필요해요" 안내를 띄우는 조건으로만** 탑재.

| 게임 | 부담 요소 | 조건 |
|---|---|---|
| 수호대작전(○○지켜라) | 지킬 간식·물건 필요 | "간식 준비" 안내 |
| 그림 옮기기(텔레스트레이션) | 종이/펜 or 폰 릴레이 세팅 | 소규모만 |
| 몸으로 이어 말해요 | 릴레이 공간·인원 세팅 | 6명+ |
| 이미지 가위바위보 | 팀 합·공간 필요 | 대강당만 |
| 모여라 게임 | 넓은 공간 필수 | 대강당만 |
| 코끼리코 | 어지럼·안전 주의 | 벌칙 한정 |
| 진실 or 도전 | 수위 관리 부담 | 순한맛 슬라이더 |
| 거울 댄스 | 음악·공간 | 바이럴용으로 유지 |

## C등급 — 현실 레크 부적합 (제외)

**여기가 핵심.** 태그상 적합해 보였지만 현실에선 안 되는 것들. 냉정하게 뺀다.

| 게임 | 제외 이유 |
|---|---|
| **고요 속의 외침** | ❌ 노이즈캔슬링 헤드폰이 인원수만큼 필요. 현실 불가능(방송이니까 된 것) |
| **현미경 퀴즈(줌인)** | ❌ 고품질 확대 이미지 대량 제작 부담, 진행자가 못 만듦 |
| **인트로 맞히기(음악/시그널)** | ❌ 저작권 지뢰. 생활소음 버전도 제작 부담 큼 |
| **리듬 술래(딸기/두부)** | △ 룰 복잡, 술 없으면 동력 약함. 초보 진행자 어려움 |
| **숫자 리듬(뻔데기)** | △ 룰 설명 난이도 높음, 금방 시들 |
| **리듬 초성(아이엠그라운드)** | △ 리듬 유지 어려움, 소수만 재밌음 |
| **천지창조** | △ 2인 단위, 대규모 진행 불가 |
| **한 단어 스파이(코드네임)** | △ 앞선 조사서 "정적·지루" 실패 사례. 두뇌게임은 레크에 안 맞음 |
| **찰떡 호흡** | △ 이심전심과 중복, 짝 단위 한계 |
| **소수의 선택** | △ 투표 집계 필요, 반복되면 단조 |
| **폭탄 돌리기 딜레마** | △ 시한폭탄과 기능 중복 |
| **인간 스피드 퀴즈(특기대회)** | △ 미니게임 세팅 과다 |
| **운명의 쪽지** | △ 익명 배분 복잡, 심리전이 무거움 |
| **포커페이스** | △ 단발성, 금방 끝남 |
| **TMI 자기소개** | △ 게임이라기보단 아이스브레이커, 약함 |
| **이어달리기 카테고리** | △ 이어말하기와 중복 |
| **우리말 지킴이** | △ 게임보다 상시 규칙, 메인 안 됨(부가기능으론 OK) |

> **제외 원칙**: 준비물 부담 / 룰 복잡 / 기능 중복 / "방송이라 됐지 현실엔 안 되는 것" / 두뇌게임(정적).
> C등급도 영구 삭제가 아니라 **"검증 후 나중에"** 보류. 지금은 S+A에 집중.

## 최종 선별 결과

```
S등급  8개 ─┐
A등급 12개 ─┼─→ 정식 서비스 20개 (검증된 것만)
B등급  8개 ─→ 조건부 (준비물 안내와 함께)
C등급 17개 ─→ 보류 (일단 제외)
```

### MVP 웹 버전 탑재 = S 8개 + A 상위 7개 = 15개

**오프닝(3)**: 청개구리 가위바위보 · 눈치 게임 · 369
**아이스브레이킹(4)**: 밸런스 게임 · 이어 말하기 · 만약에 · 손병호
**메인(5)**: 카테고리 초성 퀴즈 · 인물 퀴즈 · 몸으로 말해요 · 스피드 퀴즈 · 이심전심
**피날레(3)**: 랜덤 플레이 댄스 · 벌칙 룰렛 · 시한폭탄

> 이 15개는 **전부 방송 검증 or 국민 게임 + 준비물 0~최소 + 진행자 혼자 가능.**
> 랜덤 플레이 댄스가 피날레 겸 바이럴 엔진(영상 공유) 역할.

## 이 재분석이 기획에 주는 교훈

1. **"태그 적합 ≠ 현실 적합".** phase/place/mode가 맞아도 준비물·진행난이도에서 걸러야 함.
2. **두뇌게임(코드네임·스파이류)은 레크에 안 맞음.** 정적이고 진행자 통제가 어려움. 술자리·MT는 순발력/몸/토크가 답.
3. **방송에서 됐다고 현실에서 되는 게 아님.** 고요속의외침처럼 장비빨이면 제외.
4. **검증된 소수로 시작.** 15개로 완결 큐시트가 나오면 충분. 양보다 "터지는 것"만.
